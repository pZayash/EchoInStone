# Формат рабочей памяти

Папка `memory/` — хранилище рабочих фактов проекта в markdown-файлах.

## Принципы

- Одна запись = один `.md`-файл.
- Один факт = одна запись.
- Пиши коротко и предметно, без лишнего контекста.
- Не хранить секреты, токены, пароли, персональные данные.
- Запись должна быть самодостаточной: понятно без открытия других файлов.

## Именование файлов

Рекомендуемый шаблон:

`YYYY-MM-DD-короткая-тема.md`

Пример:

`2026-05-25-whisper-backend-selection.md`

## Шаблон записи

```md
# <Короткий заголовок факта>

## Контекст
<Где проявляется: модуль, пайплайн, change OpenSpec>

## Факт
<Что именно выяснили или о чем договорились>

## Решение / правило
<Как действовать в будущих задачах>

## Теги
<2-6 тегов; канон — [TAGS.md](../TAGS.md), например: ASR, diarization, openspec>

## Дата и источник
<YYYY-MM-DD, кто зафиксировал, ссылка на задачу/чат при наличии>
```

Словарь домена (термины пайплайна) — [CONTEXT.md](../CONTEXT.md).

## Как искать

- По смыслу: `SemanticSearch` / чтение релевантных файлов в `memory/`
- По ключевым словам: `rg "тег или фраза" memory/`

Перед нетривиальной задачей: при наличии — `CONTEXT.md` → `memory/` → артефакты `openspec/changes/`.
