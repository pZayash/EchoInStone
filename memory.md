# Память проекта

Этот файл хранит только долговременные правила высокого приоритета.

## Критерии записи в этот файл

Правило добавляется в `memory.md`, только если одновременно:

- Глобальное: действует во всем проекте.
- Критичное: нарушение ведет к серьезным последствиям.
- Стабильное: не меняется от задачи к задаче.
- Невыводимое: не следует напрямую из `AGENTS.md`,
  `README.md` и профильной документации в `docs/`.

Все остальное хранится в `memory/`
отдельными `.md`-записями (шаблон — [memory/README.md](memory/README.md))
и ищется через `rg` / `SemanticSearch` с фильтром по этой папке.
